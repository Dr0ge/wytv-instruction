# 上海市位育中学学生会信息部工作指南

本手册系上海市位育中学学生会信息部（WYTV）的内部工作规范，由历任部长共同编写。

内容涵盖每周《位育新闻》的制作流程，以及摄影、主持、剪辑、组长四类岗位的工作标准，供新任干事参照执行。

## 阅读方式

- **在线阅读**：直接查阅 [信息部工作指南.md](./信息部工作指南.md)，正文内容均集中于此文件。
- **本地阅读**：克隆仓库后，使用 Typora、Obsidian 或 VS Code 等编辑器打开，可获得更佳的渲染效果。

```bash
git clone https://github.com/Dr0ge/wytv-instruction.git
```

正文分为四卷：

| 卷 | 内容 |
| :--- | :--- |
| **通用卷** | 人员分工、场地使用、轮值安排、设备借还与操作资格考核 |
| **职业卷** | 摄影、主持、剪辑、组长四类岗位的工作标准 |
| **活动卷** | 学年活动年表、高三毕业季系列活动策划方案 |
| **进阶卷** | 多机位剪辑、600 人会场转播 |


## 修订方式

正文的修改仅需编辑 `信息部工作指南.md`，图片统一存放于 `工作手册图片/` 目录。各项操作细则、软件清单与活动方案均以正文为准，

### 提交流程

1. Fork 本仓库并新建分支；
2. 完成修改后提交 Pull Request，说明改动内容、本人身份与缘由；
3. 经审核后合并。

### 学年换届维护清单

每学年换届之际，请依此清单逐项核查，以免遗留失效信息：

- [ ] 更新人员篇：新一届高一干事名单、高二留任干事名单及指导老师信息
- [ ] 更新时间篇中的轮值表截图
- [ ] 核对设备清单与场地信息是否发生变动
- [ ] 更新活动卷中的学年大事年表
- [ ] 通读全文，删改或更正已失效的内容
